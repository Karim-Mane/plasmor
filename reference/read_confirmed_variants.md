# Import variants file depending on whether it's in a `.csv` or `.json` format

Import variants file depending on whether it's in a `.csv` or `.json`
format

## Usage

``` r
read_confirmed_variants(variants_file)
```

## Arguments

- variants_file:

  A character with the path to the variant file

## Value

A data frame of three columns with the gene IDs, the mutation, and the
name of the drug
